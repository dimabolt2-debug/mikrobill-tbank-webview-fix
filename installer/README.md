# Установщик MikroBILL T-Bank Mobile Fix 1.1

`MikroBILL-TBank-Mobile-Fix-1.1.exe` — автономный установщик исправления
редиректа Т-Банка для мобильных браузеров.

При обычном запуске установщик запрашивает права администратора, проверяет
совместимость файлов, создаёт резервную копию, устанавливает исправление во все
три каталога MikroBILL и проверяет PHP-синтаксис и SHA-256. Если любой этап
завершается ошибкой, файлы автоматически восстанавливаются из резервной копии.

Резервные копии сохраняются в:

`C:\ProgramData\MikroBILL\PatchBackups\TBankMobileRedirectFix-YYYYMMDD-HHMMSS`

Установщик принимает только исходную версию MikroBILL, первый вариант патча или
уже исправленную версию. При неизвестном SHA-256 установка останавливается, чтобы
не перезаписать файлы другой версии MikroBILL.

Параметры командной строки:

- `--verify-only` — только проверить совместимость и состояние файлов;
- `--silent` — не показывать диалоги, вернуть результат через код завершения.

EXE не подписан коммерческим сертификатом издателя, поэтому Windows SmartScreen
может показать предупреждение. SHA-256 опубликован рядом с готовым файлом.
